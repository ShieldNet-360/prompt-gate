# Getting help

Thanks for using Prompt Gate. Here's where to go, depending on what you need.

## Questions & discussion

- **[GitHub Discussions](https://github.com/ShieldNet-360/prompt-gate/discussions)**
  — usage questions, ideas, show-and-tell, and "how do I…" help. Start here for
  anything that isn't a confirmed bug.

## Documentation

- **[Docs site](https://shieldnet-360.github.io/prompt-gate/)** — quick start,
  admin guide, user guide, pattern authoring.
- **[Quick Start](https://shieldnet-360.github.io/prompt-gate/quickstart/)**
  — build and run in a few commands.
- **[Whitepaper](https://shieldnet-360.github.io/prompt-gate/whitepaper/)** —
  how the engine works and why.

## Bugs & feature requests

- **[Open an issue](https://github.com/ShieldNet-360/prompt-gate/issues/new/choose)**
  using the bug-report or feature-request template. Include your OS, version
  (`prompt-gate-agent --version`), and steps to reproduce.
- Before filing, search existing issues — it may already be tracked.

## Security vulnerabilities

**Do not** open a public issue. Follow coordinated disclosure per
[SECURITY.md](SECURITY.md).

## Verifying what you run

Prompt Gate is built to be checkable, not just trusted:

- Verify release integrity & provenance:
  [Verifying releases](https://shieldnet-360.github.io/prompt-gate/verifying-releases/).
- Reproduce the agent binary from source:
  [Reproducible builds](https://shieldnet-360.github.io/prompt-gate/reproducible-builds/).

## Contributing

Want to help? See [CONTRIBUTING.md](CONTRIBUTING.md) and
[GOVERNANCE.md](GOVERNANCE.md). Issues labelled
[`good first issue`](https://github.com/ShieldNet-360/prompt-gate/labels/good%20first%20issue)
are a friendly place to start.
